**Decision Title:** SvelteKit-integrated service worker with build-aware pre-caching

**Status:** Accepted (supersedes static service worker)

**Date:** 2026-04-01

1. **Context:** The original service worker was a static file at `static/service-worker.js`. It could not pre-cache SvelteKit's hashed build output (e.g., `_app/immutable/chunks/abc123.js`) because it had no way to know the filenames at build time. This caused JS/CSS chunks to fail with 503 errors when the user went offline.

2. **Decision:** Move the service worker to `src/service-worker.ts` and use SvelteKit's `$service-worker` module for build-aware pre-caching.

3. **Rationale:**
   - SvelteKit provides `build`, `files`, and `version` imports from `$service-worker`:
     - `build` — array of all hashed JS/CSS chunk paths generated by Vite
     - `files` — array of all files in the `static/` directory
     - `version` — unique string per build, used as the cache key
   - This guarantees that **every** build asset is pre-cached on install, enabling full offline functionality.
   - The versioned cache name (`animal-identifier-${version}`) ensures old caches are cleaned up on new deploys.

4. **Consequences and Risks:**
   - **Build version mismatch** — when a new build deploys, an old SW may intercept requests for new chunks it doesn't have. Mitigated by detecting uncached `/_app/immutable/` requests and passing them through to the network via `fetch()` instead of returning 503.
   - **Pre-cache size** — caching ~50+ build assets on install adds a brief delay on first visit. This is acceptable for a PWA that targets repeat usage.
   - **App shell caching** — pages like `/dashboard` and `/login` are cached individually during install, with graceful fallback if any fail (e.g., auth redirects).

5. **Caching Strategy:**

| Request Type | Strategy |
|---|---|
| Navigation (online) | Network-first, cache response, fall back to cache or root shell |
| Navigation (offline) | Cache-first, fall back to root shell `/` |
| Immutable build assets | Cache-first; if not cached, pass to network (no 503) |
| Other static assets | Cache-first with network update |
| API requests (`/api/*`) | Network-only (503 if offline) |
